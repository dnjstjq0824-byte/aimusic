# AVIBE 브랜드 로고

마스터 파일은 이 폴더의 SVG 두 종이다. 앱별 복사본(`web/public/favicon.svg`,
`web/src/assets/logo.svg`, `mobile/assets/logo.svg`)은 마스터와 바이트 동일을
유지하고, 수정 시 마스터부터 고친 뒤 복사한다.

- `logo.svg`: 풀컬러 마크. 딥파인 타일 + 앰버→코랄 파형 바 + 다크 플레이
  녹아웃 + 크림 AI 스파크. 웹 헤더·파비콘·앱바·스플래시용.
- `logo-mono.svg`: 단색(화이트) 마크. 타일 없음. 잠금화면·알림·단색 인쇄용.

브랜드 컬러:

| 용도 | 값 |
|---|---|
| 타일 상/하 | `#132826` / `#0B1B18` |
| 파형 좌/우 | `#FFC53D` / `#FF5A3C` |
| 플레이 녹아웃 | `#0F201D` |
| 스파크 | `#FFF3E2` |
| 웹 액센트(brand-500/600/700) | `#FF6B3D` / `#E5522B` / `#B93F22` |

PNG·런처 아이콘은 릴리즈 전에 SVG에서 변환한다. (현재 환경에 래스터
변환기가 없어 SVG 원본만 둔다.)
