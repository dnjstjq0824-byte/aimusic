# GPU 운영안 비교표 (WI-G3, PO 결정용)

G1 호스팅 단계의 운영 GPU 선택을 위한 비교 틀이다. **구매·가입 금지** —
아래 표의 가격 칸은 PoC 실측 + 견적일에 채운다. 숫자 없이 결정하지
않는다. 핵심 지표 = **생성 1분당 원가**.

## 1. 1분당 원가 추정식

웜 상태와 콜드 상태를 분리해 계산한다:

- **웜 호출**: `infer_sec × $/GPU-sec / audio_min`
- **콜드 호출**: `(coldstart_sec + infer_sec) × $/GPU-sec / audio_min`
- **월 추정**: `(웜 호출 수 × 웜 원가 + 콜드 호출 수 × 콜드 원가) + 최소 과금·대기 비용`

입력값 출처:

| 입력 | 출처 | 상태 |
|---|---|---|
| `infer_sec_per_audio_min` (GPU 기종별) | WI-G2 PoC 실측 | NOT TESTED |
| VRAM 사용량 (기종 하한) | WI-G2 PoC 실측 | NOT TESTED |
| `$/GPU-sec`, 최소 과금 단위 | 공급사 요금 페이지 (견적일 캡처) | TBD |
| 콜드 스타트 실측 | 후보 2곳 무료 티어 실측 (가입은 PO 승인 후) | TBD |

## 3. 공급사별 확인 체크리스트 (계약 전)

1. 입력(프롬프트·가사)·출력(음원)을 학습·평가에 재사용하는가?
2. 파일·로그 보존 기간과 삭제 요청 경로가 있는가?
3. 리전 고정(데이터 상주지)이 가능한가? (개인정보 국외이전 검토와 연결)
4. 워터마크·유사도 검사는 AVIBE 측에서 수행 — 공급사에 원본 보관
   의무를 지우지 않는다.
5. 장애·검열 시 대체 공급사로의 전환 절차 (벤더 종속 회피).

## 4. 결정 게이트

- G-MODEL 통과 전에는 운영 투입 없음 — 이 비교표는 G1 진입 조건
  (§2 "G1 호스팅" 행) 충족 시점에 PO가 선택한다.
- 사용량이 일정 수준을 넘으면 예약 GPU로 전환 검토 (별도 TCO 산정).
- 선택 결과는 `generation_models` 운용 메모 + 모델 카드에 기록한다.
