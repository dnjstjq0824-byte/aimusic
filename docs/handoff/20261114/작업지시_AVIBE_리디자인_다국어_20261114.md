## 3. P1 — 플랫폼 전환

### WI-P1. Vite SPA → Nuxt 4 이전 (화면 변화 없이 동등 이전)
- Nuxt 4 최신 안정판 **정확한 버전 고정**(Nuxt 3 금지 — OSS 지원 2026-07-31 종료). `@pinia/nuxt`, Tailwind 유지.
- 기존 `views/**` → `pages/**`, `layouts/**` 이동. 라우트 가드 → 라우트 미들웨어(`auth`, `role`), `safeRedirect` 유지·테스트 이전.
- `routeRules`: 우선 전 경로 CSR로 시작해 동등성 확보 → 공개 경로만 SSR 전환(SEO 설계서 §2 표). SSR 경로는 로그인 여부와 무관하게 같은 HTML.
- 브라우저 전역 접근은 `onMounted`·`.client.vue`·`import.meta.client`로 격리. hls.js·Toss SDK는 지연 로드.
- 배포: Nitro 프리셋을 Cloudflare Workers(`cloudflare_module` — 착수 시 철자 확인)와 Node 서버 둘 다 빌드되게. 기존 `worker.js`는 **앞단 유지**, 페이지 요청만 Service Binding으로 Nuxt Worker에 전달(재생 권한·HLS 프록시 코드 무변경, `scripts/worker-grant.test.mjs` 통과 유지).
- 기존 `vitest` 테스트는 Nuxt 테스트 환경으로 이전, 전부 통과.
- 수용: WI-R0 기준선 하네스를 그대로 돌려 **화면 차이 0(픽셀 비교 허용 오차 내)**, E2E PASS. 배포 대상 결정(Workers Paid vs VPS Node)은 PO(SEO 설계서 §1.1).

### WI-R1. 디자인 토큰 v2 + Ui 컴포넌트 (재정의서 §4)
- 토큰: `text-muted #8A909C`, `verified`, `success #22C55E`, `focus`, 타이포 7단계, 간격·반경·브레이크포인트, `:lang()` 글꼴 스택, 태국어 행간, ko/en 한정 음수 자간.

### WI-R2. i18n 기반 (재정의서 §5, SEO 설계서 §3)
- `@nuxtjs/i18n`, 전략 `prefix_except_default`(ko 기본), 로케일 `ko·en·ja·zh-cn·th` + 개발용 `en-XA`. 네임스페이스 지연 로딩.
- **언어 접두는 공개 페이지에만.** 인증·개인·결제·스튜디오·콘솔·관리자·매장 플레이어는 접두 없이 한 경로(UI 구조서 §1 "언어 접두 규칙"). 경로 고정 화면(`/oauth/callback`, `/reset-password`, `/verify-email`, `/checkout/confirm`, `/certificate/:number`, `/store/player`)은 이름을 바꾸지 않는다.
- 감지: 사용자 locale > 저장값 > 브라우저. **Accept-Language 강제 리다이렉트 금지** — 다른 언어 제안 배너 1회.
- 언어 선택지에 ja·zh-CN·th는 "Beta" 배지(G-L 해제 전).
- `scripts/check-i18n.mjs`(한글 하드코딩·키 동치·미사용 키·ICU 검사) CI 필수. P1~P4는 허용목록 모드, P5 전역 강제.
- 공통 키화: 탭 제목·가드 토스트·내비·푸터·플레이어·토스트·오류 배너·API 오류 코드 매핑. `useFormat`(날짜·숫자·통화)로 `toLocaleString` 직접 호출 전부 교체.

**공급자**: Google(있음) · Kakao(있음) · **Apple · Naver · LINE(신규)**. WeChat은 어댑터 인터페이스만(중국 법인 필요 — 구현 보류).

**환경변수 (전부 있으면 자동 활성, 하나라도 없으면 비활성 + 시작 로그에 빠진 변수 이름만 경고):**
| 공급자 | 필수 | 선택 |
|---|---|---|
| Google | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | |
| Kakao | `KAKAO_CLIENT_ID`(REST API 키) | `KAKAO_CLIENT_SECRET`(콘솔에서 켰을 때) |
| Apple | `APPLE_SERVICES_ID`, `APPLE_TEAM_ID`, `APPLE_KEY_ID`, `APPLE_PRIVATE_KEY`(p8 PEM 내용) | |
| Naver | `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | |
| LINE | `LINE_CHANNEL_ID`, `LINE_CHANNEL_SECRET` | |
| 공통 | `OAUTH_REDIRECT_BASE_URL`(예 `https://avibemusic.com/api/v1/auth/oauth`), `OAUTH_STATE_SECRET` | |

콜백 URI = `{OAUTH_REDIRECT_BASE_URL}/{google|kakao|apple|naver|line}/callback` — 각 개발자 콘솔에 이 값 그대로 등록.

**구현 요건**
1. 공급자별 어댑터 인터페이스(`AuthURL`, `Exchange`, `Identity`)로 정리, 기존 Google·Kakao 이전. `Providers()`는 활성 목록 + 표시 순서(언어별)를 반환.
2. Apple: `response_mode=form_post` 콜백(POST) 처리, client_secret은 ES256 JWT를 요청 시 생성(짧은 만료), id_token을 Apple JWKS로 검증(iss·aud·exp·nonce), 이름은 최초 인증 때만 오므로 그때 저장. 비공개 릴레이 이메일 허용.
3. LINE: OIDC(`openid profile email`), id_token 검증(iss·aud·exp·nonce). 이메일 권한은 콘솔 신청 필요 — 없으면 4번 흐름.
4. **이메일 미제공**(LINE·Naver 선택 동의 거부 등): 임시 가입 토큰 → `/signup/complete-email` → 이메일 인증(A2) 후 계정 생성·연결.
5. **보안 수정**
   - (C-11) 같은 이메일 기존 계정 **자동 연결은 공급자가 이메일 인증을 보증할 때만**(Google·Apple `email_verified`, Kakao `is_email_verified`·`is_email_valid`). 그 외에는 "기존 계정으로 로그인 후 연결" 안내 → `/account/connections`에서 연결.
   - (C-12) state를 브라우저에 묶는다: HttpOnly·Secure·SameSite=Lax 쿠키 nonce + 서명 + 10분 만료, 1회용. 지원 공급자는 PKCE(S256), OIDC는 nonce 검증. Apple은 form_post(교차 사이트 POST)라 SameSite=Lax 쿠키가 안 붙으므로 Apple 전용 state 쿠키는 `SameSite=None; Secure`로 따로 둔다.
   - (C-16) 콜백이 **access·refresh 토큰을 URL 쿼리로 넘기는 방식 제거**(`handler/auth.go` OAuthCallback → `/oauth/callback?accessToken=…&refreshToken=…`). 브라우저 기록·서버 로그·Referer로 새어 나간다. 대신 60초 만료·1회용 교환 코드를 넘기고, 웹이 `POST /auth/oauth/exchange`로 토큰을 받는다. `/oauth/callback` 경로는 유지.
6. 웹: `SocialButtons`가 활성 공급자만 공식 브랜드 가이드 스타일로 렌더. 모바일은 WI-R12에서 시스템 브라우저 + 앱 링크 복귀.
7. 테스트: 공급자별 스텁 서버 테스트(기존 `oauth_test.go` 패턴), Apple JWT 서명·form_post, 미검증 이메일 자동 연결 거부, state 재사용·만료·쿠키 불일치 거부, 교환 코드 재사용·만료 거부, 콜백 리다이렉트 URL에 토큰 문자열 0, **환경변수를 넣고 빼는 것만으로 활성/비활성이 바뀌는 테스트.**
8. 문서 `docs/OAUTH_SETUP.md`: 공급자별 콘솔 절차, 정확한 콜백 URI, 필요한 권한(Kakao 이메일 동의항목은 비즈 앱 전환 필요, LINE 이메일 권한 신청, Apple Services ID·도메인 확인, Naver 검수), `.env` 예시(값은 빈칸). 키 반영 = `.env` 추가 + API 컨테이너 재시작뿐임을 명시.

6. 비밀값(소셜 키·Apple p8·R2·Toss·JWT·IndexNow 키)을 저장소·로그·보고서에 남기지 않는다. `.env` 예시는 빈 값.
7. 학습 금지 데이터(준비계획서 §3.1)를 어떤 형태로도 학습·평가셋에 넣지 않는다. 파트너 업로드 곡 포함.
8. 기계 번역은 `machine-draft` 표기, ja·zh-CN·th는 "Beta".
9. 화면 변경은 1440·390 전후 캡처 + 최소 th·ja 캡처.
10. 기존 테스트 전부 통과 유지. 테스트 삭제로 통과시키지 않는다.
11. 구 URL은 리다이렉트로 보호(북마크·메일 링크·검색 색인).
