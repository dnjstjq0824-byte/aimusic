## 3. 잘 되어 있는 것 (유지)
- 390px에서 가로 스크롤 0건, iOS 입력 확대 방지(16px), safe-area 유틸.
- 개발용 빠른 로그인 버튼이 `isDev`로 운영에서 숨겨짐.
- 404·인증서 무효·약관 화면이 존재하고 깨지지 않음.
- 환불 정책 문구가 요금제·결제에 일관 적용.
- 인증서 미발급 곡에 인증 배지를 붙이지 않는 규칙(U-01) 준수.
