| 항목 | 내용 |
|---|---|
| 발행 | CEO/PO |

## 1. 왜 우리가 만들면 이기는가 — "Born Verified"

- 다른 생성 서비스의 곡은 **만든 뒤에** 권리를 따져야 한다. 요금제·다운로드 시점·약관 개정에 따라 결론이 바뀐다.
- AVIBE에서 생성된 곡은 **태어날 때부터 인증된다.** 모델 버전 → 학습 데이터 목록(dataset manifest) → 생성 파라미터 → 워터마크 → 인증서까지 하나로 이어진다. 그대로 매장 BGM·영상 라이선스로 팔린다.
- 생성 품질 경쟁만으로는 이기기 어렵다. **"학습 데이터까지 깨끗한 모델 + 즉시 상업 이용 + 수요처(매장·영상)"** 의 조합은 지금의 유통·인증 플랫폼에서만 나온다. 이것이 해자다.

## 2. 단계

| 단계 | 모델 | 데이터 | 진입 조건 |
|---|---|---|---|
| **G1 호스팅** | 상업 이용 가능한 오픈 가중치(ACE-Step — Apache-2.0/MIT, 착수 시 버전별 라이선스 재확인) | 학습 안 함(추론만) | 워터마크·출처 기록·안전 필터·인증 연동 완료, 품질 평가 통과 |
| **G2 미세조정** | G1 모델 + AVIBE 라이선스 데이터로 미세조정(LoRA 등) | 라이선스·동의 데이터만 | 데이터 원장 가동, 동의 약관 법률 확인, 평가에서 G1 대비 선호도 우위 |
| **G3 자체 기반 모델** | 자체 아키텍처, 처음부터 학습 | 전량 라이선스 코퍼스 | 데이터 규모·학습 예산 확보, 외부 "라이선스 데이터 학습" 인증 획득 목표(Fairly Trained 등) |

단계 이동은 PO 게이트 **G-MODEL**(§8)을 통과해야 한다.

## 3. 데이터 원칙 — 가장 중요하다

주요 생성 서비스들이 학습 데이터 때문에 음반사 소송과 합의를 거쳤다. 우리는 처음부터 다르게 한다.

### 3.1 학습 금지 데이터 (예외 없음)
1. **다른 AI 서비스의 생성물** — 파트너가 AVIBE에 올린 Suno·AIVA·ElevenLabs 등의 곡 포함. Suno 약관은 출력물을 다른 AI 모델 학습에 쓰는 것을 금지하는 것으로 확인된다(제3자 미러 기준, 원문 재확인 필요). 다른 공급자도 같다고 가정한다.
2. 상업 음원·유튜브·스트리밍에서 수집한 녹음.
3. 파트너 업로드 곡 중 **별도 학습 동의가 없는 곡** — 유통 계약 동의는 학습 동의가 아니다.
4. 사용자의 프롬프트·가사 — 별도 동의 전에는 학습·평가셋에 넣지 않는다.

### 3.2 허용 데이터
| 출처 | 조건 |
|---|---|
| 의뢰 제작(세션 연주자·작곡가) | 계약서에 **AI 학습 권리 명시**, 업무상 저작물 또는 양도 |
| 라이선스 구매 카탈로그(프로덕션 뮤직 라이브러리 등) | 라이선스에 학습 범위·지역·기간 명시 |
| 크리에이터 학습 참여 프로그램 | **별도 옵트인**, 수익 배분, 향후 학습 철회 가능(이미 학습된 모델 버전은 원장에 기록), 기본값 꺼짐 |
| 퍼블릭 도메인 작품의 **새 녹음** | 작곡은 PD여도 녹음은 별도 권리 — 새로 녹음한 것만 |
| CC0 녹음 | 출처·라이선스 스냅샷 보관 |
| 자체 모델 합성 데이터 | 비율 상한, 원장에 "합성" 표기 |

### 3.3 데이터 출처 원장 (Data Provenance Ledger)
- 파일 단위: 해시, 지문, 출처, 권리자, 라이선스 문서 ID, 동의 ID, 허용 범위(학습/평가/데모), 지역, 기간, 철회 상태.
- 데이터셋 매니페스트: 원장 항목 목록의 불변 스냅샷 + 해시. **모든 모델 버전은 매니페스트 해시를 가리킨다.**
- 원장은 추가 전용(append-only). 수정은 새 항목 + 이전 항목 무효화.
- 저장: 원본 오디오는 별도 R2 버킷(학습 전용, 공개 경로 없음), 메타는 Postgres.

## 4. 시스템 구조

```
[웹/모바일 생성 UI] → [Go API: 크레딧 차감·안전 검사·작업 생성] → [Redis 큐]
      → [Generation Service (Python FastAPI, GPU)]
           ├─ 모델 레지스트리(이름·버전·가중치 해시·라이선스·매니페스트 해시·모델 카드)
           ├─ 추론(시드·파라미터 기록 = 재현 가능)
           ├─ 워터마크 삽입
           └─ 결과 → R2
      → [Go 워커: 유사도 검사 → 라이선스 게이트(공급자 = AVIBE) → HLS 변환 → 인증서 발급]
      → [트랙: origin = AVIBE_MODEL, "Born Verified"]
```

- 현재 `generator` 계약(`POST /generate` → WAV base64)을 **v2로 버전 관리**: `contractVersion`, `modelId`, `modelVersion`, `seed`, `durationSec`, `variations`, `stems`(선택), `watermark: true`(강제), 응답에 `weightsHash`, `safety`, `watermarkId`. 대용량은 base64 대신 R2 사전서명 업로드.
- GPU: G1 개발은 기존 GPU PC, **운영은 초당 과금 서버리스 GPU**(공급사 선택은 WI-G3에서 비용표로 PO 결정), 사용량이 일정 수준을 넘으면 예약 GPU. 핵심 지표 = **생성 1분당 원가**.
- 학습 인프라(G2~): 실험 추적, 데이터 버전 관리(R2 기반), 평가 하네스. 운영 VPS와 분리.

## 5. 생성물 안전·출처 표시

| 장치 | 내용 |
|---|---|
| 프롬프트 필터 | 현행 키워드 가드를 다국어로 확장: 실존 가수·밴드 이름, "~ 스타일로/풍으로", 목소리 복제 요청 차단. 5개 언어 목록 + 정규화(띄어쓰기·전각) |
| 가사 검사 | 사용자가 넣은 가사가 기존 곡 가사를 베꼈는지 — 1차는 사용자 확인 + 신고 경로, 2차로 자동 검사 도입 검토 |
| 유사도 검사 | 생성 결과 지문을 자체 카탈로그·학습셋과 대조(암기·복제 탐지). 임계 초과 시 결과 폐기 + 기록 |
| 워터마크 | 들리지 않는 오디오 워터마크(오픈소스 후보: AudioSeal — 라이선스·강건성은 WI-G2 PoC에서 확인) + 다운로드 파일에 C2PA 콘텐츠 자격증명 + 메타데이터 태그 |
| AI 생성 표시 | 인공지능기본법 표시 의무(현재 트랙 화면의 AI 생성 표시 블록 재사용), EU 시장 대상 시 AI Act 제50조 기계 판독 표시 — 적용 시점·범위는 출시 전 법률 확인 |
| 인증 | 공급자 정책에 `AVIBE` 추가 → 생성물은 라이선스 게이트를 자동 통과하되 **유사도·워터마크 검사 통과가 조건**. 인증서에 모델 버전·매니페스트 해시 표기 |

## 6. 권리·약관 설계 (초안 방향 — 게시는 법률 확인 후 G-3)
- 유료 플랜 생성물: 사용자에게 권리 양도(또는 독점적 이용권) + AVIBE에 유통·홍보 이용권. 무료 플랜: 비상업.
- 저작권 한계 고지: AI 단독 생성물은 저작권 등록이 제한될 수 있다. 사용자의 기여(직접 쓴 가사, 편집, 구성)를 생성 기록에 남겨 증빙할 수 있게 한다.
- 프롬프트·가사의 학습 이용은 별도 동의.
- 크리에이터 학습 참여 프로그램 계약(수익 배분 방식은 PO 결정).

## 7. 제품 경험 (지금 화면 구조에 자리를 잡아 둔다)
- 공개 `/create`: 지금은 "곧 출시" 소개 + 대기자 등록, 출시 후 생성 진입점.
- 홈 히어로 검색 바는 "듣기/만들기" 모드 토글이 들어갈 자리를 둔다(UI 구조서 §3.1).
- 스튜디오 `/studio/create`: 프롬프트 · 스타일 태그 · 가사 · 길이 · 변형 2개 · 이어 만들기 · 스템 내보내기 · [인증 요청].
- 크레딧: 추가 전용 원장(`credit_ledger`), 요금제별 월 지급, 실패한 생성은 자동 환불. **가격은 PO 결정 전 미표시.**
- 모델 투명성 페이지 `/models/:slug`: 모델 카드(용도·한계·학습 데이터 출처 범주·평가 결과·라이선스).
- 공개 표시: 생성 곡에 "Made with AVIBE" 라벨 + 모델 버전.

## 8. 평가와 출시 게이트 G-MODEL
모델 버전마다 아래가 모두 있어야 운영 투입:
1. 모델 카드 2. 데이터셋 매니페스트 해시 3. 자동 평가(FAD 등 음질 거리, CLAP 계열 프롬프트 일치도) 4. **사람 선호 평가**(앱 내 A/B 쌍대 비교 — 일정 표본 이상) 5. 암기 테스트(학습셋 대비 유사도) 6. 안전 레드팀 결과(아티스트 모방·혐오 가사 등) 7. 워터마크 강건성(압축·재녹음) 8. 법률 확인.
