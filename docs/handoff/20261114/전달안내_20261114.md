## 확정된 결정
- 비즈니스 요금: 가격 없이 **도입 문의**.
- 번역: 한국어 원문 + 영어·일본어·중국어 간체·태국어. 영어 외 3개는 **Beta** 표기.
- 소셜 로그인: Google·Kakao·Apple·Naver·LINE을 **키만 넣으면 작동**하게 완성(보안 결함 C-11·C-12·C-16 먼저 수정).
- 경로 고정 화면(엔진·메일·Toss가 주소를 만드는 곳)은 주소 불변, 언어 접두는 공개 페이지에만.
- 개인정보처리방침·약관 개정안은 초안만(WI-L1), 게시는 법률 확인 후.
- 웹: Vite SPA → **Nuxt 4 SSR**, 공개 페이지는 언어별 URL.
- 라이브러리와 플레이리스트는 **별개 페이지·별개 메뉴**.
