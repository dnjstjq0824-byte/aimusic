**언어 접두 규칙:** "공개" 묶음만 언어 접두(`/en/…`)를 갖는다. 인증·개인·결제·스튜디오·콘솔·관리자·매장 플레이어는 **접두 없이** 하나의 경로를 쓰고, 표시 언어는 사용자 설정을 따른다. `※ 경로 고정` 화면은 엔진·메일·Toss·QR이 주소를 직접 만들므로 이름을 바꾸지 않는다.

### 1.1 라이브러리와 플레이리스트는 다른 페이지다
| | 라이브러리 `/library` | 플레이리스트 `/playlists` | 내 플레이리스트 `/me/playlists` |
|---|---|---|---|
| 질문 | "내가 모아둔 것은?" | "무엇을 들을까?" (발견) | "내 목록 관리" |
| 내용 | 좋아요한 곡, 최근 재생, 저장한 곡, 팔로우한 크리에이터·플레이리스트 | 에디터 큐레이션, 무드·용도별, 인기, 추천 믹스, (로그인 시) 내 플레이리스트 레일 1줄 | 내가 만든 플레이리스트 목록, 생성·이름변경·삭제·공개 설정 |
| 로그인 | 필요 | 불필요 (SSR·검색 노출) | 필요 |
| 내비 | 1차 메뉴 | 1차 메뉴 | 플레이리스트 화면의 "내 플레이리스트" 탭/레일에서 진입 |

- 현재 `MyLibrary.vue`의 플레이리스트 섹션·생성 모달·삭제 확인은 **라이브러리에서 제거**하고 `/me/playlists`로 옮긴다. 라이브러리에는 "내 플레이리스트 n개 →" 링크 카드 1개만 둔다.
- 이용권·해지 영역은 `/account/billing`으로 옮긴다.
- 플레이리스트 상세 `/playlists/:slug`는 공개 플레이리스트면 SSR, 비공개면 소유자만 CSR로 열린다.
