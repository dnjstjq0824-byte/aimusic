## 3. 신규 작업 항목 (EV)

### EV-01. 헤더 '내 라이브러리' 링크 정정 (예상 2개)
- 헤더 링크가 /library(404)로 간다. 사용자 메뉴의 동일 항목은 /my-library로 정상 — 헤더 쪽을 정본 경로로 맞춘다.
- 전 표면의 동일 라벨 링크(헤더·히어로·푸터·모바일 메뉴) 목적지를 전수 대조해 불일치를 함께 보고한다 (히어로 2종은 저녁 실측에서 NOT TESTED였으므로 이 항목에서 클릭 확인까지 포함).

### EV-02. 탐색 태그·무드 필터 충돌 수정 (예상 3개)
- 태그 #Cyberpunk 클릭 시 무드 필터가 'Cyberpunk & Synth'로 바뀌며, 그 태그가 붙은 곡이 있는데도 0건이 된다.
- 태그와 무드는 독립 필터로 동작하게 하고, 태그 적용 시 해당 태그 곡이 결과에 나오는 것을 완료 조건으로 한다. 필터 조합(태그+무드+플랫폼+정렬) 각각의 결과 건수를 보고에 첨부한다.

### EV-03. 플레이리스트 재생 안내-실행 일치 (예상 2개)
- '최신 업로드 재생'이 "3곡을 재생합니다" 토스트를 띄우고 실제로는 재생되지 않는다 (로그인 필요로 차단).
- 재생할 수 없으면 성공형 안내를 띄우지 말고 실제 사유를 안내한다. 로그인 상태에서 실제로 재생되는지도 함께 확인해 보고한다.

### EV-04. 법적 문서 렌더링 정비 (예상 4개)
- 약관·정책 5종 본문에 '\n' 문자가 그대로 노출되고 전체가 굵은 청록 단일 문단으로 보인다 — 실제 줄바꿈·문단·조항 위계로 렌더한다.
- TOS 본문의 내부 파일 경로 참조(docs/legal/terms-of-service.md)를 사용자 화면에서 제거한다.
- "(사업자 등록 후 기재)" 문구 노출은 SC-04 규칙과 동일하게 처리한다 (값이 없으면 해당 표기 자체를 숨김).
- 게이트 G-3 유지: 본문 내용 자체의 게시·변경은 법률 확인 후 PO 승인. 이 항목은 렌더 방식만 고친다.

### EV-05. 목록·통계 로딩 안정화 (예상 4개)
- 홈 재방문 시 목록이 0건으로 떴다가 같은 세션에서 3건으로 바뀐다. 파트너 대시보드 통계와 구독 증빙 목록도 첫 진입 시 0으로 떴다가 실제 값으로 바뀌는 동일 패턴이 확인됐다.
- 로딩 중에는 스켈레톤을 유지하고, 완료 후에만 확정 건수를 표시한다. 원인이 API 응답 변동이면 프론트에서 숨기지 말고 엔진 측 원인으로 분리 보고한다.

### EV-06. 로그아웃 시 재생 정지 (예상 2개)

## 4. 변경 범위 가드레일 (전 항목 공통, 위반 시 반려)
1. 항목별 예상 파일 수를 넘길 것 같으면 커밋 전에 멈추고 변경 목록부터 보고한다.
2. 전체 상한 45개 초과가 불가피하면 작업을 나눠 후속 지시로 분리 제안한다.
3. 지시서에 없는 파일을 고쳤으면 별도 커밋으로 분리하고 사유를 적는다. 비밀번호 찾기(/reset-password)는 범위 밖 — 어떤 이유로도 건드리지 않는다.
4. 빌드 산출물·생성 파일은 커밋하지 않는다 (.gitignore 점검 포함).
5. 완료 보고에 `git diff --stat` 기준 전체 변경 파일 목록 + 파일별 대응 항목 번호(EV-xx / SC-xx) 매핑표를 첨부한다.
6. 신규 생성 파일과 삭제 파일은 수정과 구분해 별도로 센다.

## 7. Annex EV-P — 파트너 구간 (저녁 실측 32건: PASS 20 · FAIL 8 · NOT TESTED 4)

### EV-P01. '파트너 프로필' 버튼 무반응 수정 (예상 1개)
- 스튜디오 헤더의 '파트너 프로필' 버튼을 눌러도 아무 동작이 없다 (2회 확인). 실제 프로필 화면으로 연결하거나, 연결할 화면이 없으면 버튼을 제거한다.

### EV-P02. 업로드 날짜 선택 버튼 동작 (예상 2개)
- 업로드 Step 1의 '날짜 선택'(달력) 버튼이 열리지 않아 생성일시를 키 입력으로만 넣을 수 있다. 달력 선택기가 열리고 선택값이 필드에 반영되는 것을 완료 조건으로 한다.

### EV-P03. 트랙 상세 표기 정비 (예상 2개)
- BPM이 소수점 14자리(190.39999389648438)로 표시된다 — 정수 또는 소수 1자리로 표기한다.
- 트랙 제목 h1이 1920에서도 말줄임으로 잘린다 — 제목은 전체 표시한다. 고유 ID는 복사 가능한 형태로 전체를 볼 수 있게 한다.

### EV-P04. 2단계 인증 상태 표시 단일화 (예상 2개)
- 계정 보안에서 '2단계 인증 설정 시작'과 '2단계 인증 끄기'가 동시에 표시돼 현재 상태를 알 수 없다. 실제 상태에 맞는 동작 하나만 표시하고 현재 상태 문구를 명시한다.

### EV-P05. 대시보드 요금제 표기 실데이터 일치 (예상 1개)
- 증빙이 SUNO/Pro 1건뿐인데 대시보드가 "Suno, AIVA Pro 등"으로 표시한다. 표기는 실제 증빙 데이터 기준으로 생성한다.
