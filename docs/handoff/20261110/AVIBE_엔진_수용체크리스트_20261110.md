# AVIBE 내부 엔진 수용 체크리스트 (2026-11-10)

역할 분담: 내부 엔진 = Muse Spark 1.3 (별도 세션) / 검증·판정 = 본 체크리스트. 껍데기(화면) 작업은 현재 담당이 없어 보류 — 이 체크리스트 범위 밖.
기준 문서: `AVIBE_종합검토_보고서_20261110.md` (정본). 엔진 쪽 완료 보고가 오면 아래 항목을 라이브 실측으로 대조한다. 증거 없는 항목은 PASS로 치지 않는다.

## E-1. 서버·결제 정상화 (전제 조건)
- [ ] API가 정식 도메인으로 붙어 있음 (임시 터널 주소 0건, 530 재발 없음) — 확인법: avibemusic.com에서 음원 목록·요금제가 실제로 불러와짐
- [ ] 토스 결제 키 설정 완료, 테스트 결제 1건 성공 캡처
- [ ] canonical·도메인 표기 avibemusic.com으로 통일

## E-2. 인증 게이트 (허브의 본체)
- [ ] 외부 플랫폼 곡 등록 시: 유료 플랜 증빙(영수증 등) + 생성일 윈도우 대조 + Sync-Only 차단 + SHA-256 중복 검사 4단계가 실제로 동작 (우회 등록 시도가 거부되는 것까지 확인)
- [ ] 인증 시점에 **제공자 정책 스냅샷 저장** (어느 플랫폼·어느 날짜 정책으로 인증했는지 기록이 남음)
- [ ] 인증서 문구가 "상업적 이용권 보유 인증"으로 통일 ("100% 보장"·"소유권 보장" 문구 0건)
- [ ] 허용 모델 화이트리스트 적용 — 비상업 라이선스 모델(MusicGen 등) 생성물은 인증 단계에서 차단

## E-3. 생성 엔진 연결 (자체 생성)
- [ ] 허용 모델만 연결 (ACE-Step·HeartMuLa 등 상업 가능 라이선스), 모델별 라이선스 근거 기록
- [ ] GPU는 요청 시에만 켜지는 구조 (유휴 상시 가동 0) — 과금 로그로 확인
- [ ] 무료/유료 한도가 **코드로 강제**됨 (무료 하루 3~5곡 초과 생성 거부, 다운로드 차단이 화면이 아닌 서버에서 걸림)

## E-4. 정책·약관의 시스템 반영
- [ ] 플랜별 권리표(보고서 14-1)가 실제 권한과 일치 (무료 계정으로 상업 유통 신청이 서버에서 거부됨)
- [ ] 금지 프롬프트(실존 가수명·목소리 모방) 필터 + 제재 단계표(경고→정지→해지) 동작
- [ ] AI 표기(메타데이터+공지)가 전 곡에 자동 부착

## E-5. 정산 엔진
- [ ] 재생당 10원 고정 정산 폐기 → **순매출 70:30 (파트너 70)** 로직 (2026-11-10 정정 — 종전 풀 배분 표기 폐기, 정본은 방향결정서 5-1)
- [ ] 배분 기준 동작 확인: 직접 판매·라이선스 건은 해당 음원 귀속, 매장 구독 풀은 30초 이상 매장 재생 시간 비례
- [ ] 정산은 실유료 채널(매장·라이선스) 판매분만 집계 — 생성·일반 스트리밍 재생은 정산 원천에서 제외 (봇 사기 차단)
- [ ] 전액 몰수(FORFEITED) 폐기 확인 — 곡·기간 한정 보류(HELD) + 14일 이의신청 상태가 동작

## E-6. 유통 실무
- [ ] ISRC 발급 연동 또는 발급 대행 절차 문서화
- [ ] 글로벌 DSP 송출은 선별곡만 (대량 업로드 금지 규칙이 시스템에 있음)
- [ ] 매장 플레이어: 오프라인 캐시·영업시간 스케줄·원격 볼륨이 실기기에서 동작
